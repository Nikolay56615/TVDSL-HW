# TVDSL-HW

Домашние задания по курсу [TVDSL](https://github.com/nsu-fit/TVDSL).

- [HW1 — лексический анализ](HW1/README.md): установка, построение автоматов, запуск лексера и тестов.
- [HW2 — синтаксический анализ](HW2/README.md): установка, разбор Funny, AST, диагностика и тесты.
- [HW3 — имена и типы](HW3/README.md): установка, проверка имён и типов, определение типов локальных переменных и тесты.
- [HW4 — промежуточный код и оптимизации](HW4/README.md): установка, построение IR, анализ переменных, выполнение и тесты.

Домашние задания находятся в соседних папках. Команды из каждого README выполняются из корня репозитория.

```text
TVDSL-HW/
├── README.md
├── .gitignore
├── HW1/
│   ├── README.md
│   ├── funnylex/
│   ├── generated/
│   ├── tests/
│   └── tokens.spec
├── HW2/
│   ├── README.md
│   ├── funnyparse/
│   ├── examples/
│   ├── tests/
│   └── grammar.ebnf
├── HW3/
│   ├── README.md
│   ├── funnytypes/
│   ├── examples/
│   └── tests/
└── HW4/
    ├── README.md
    ├── funnyir/
    ├── examples/
    └── tests/
```
