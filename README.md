# TVDSL-HW

Домашние задания по курсу [TVDSL](https://github.com/nsu-fit/TVDSL).

## Установка

Нужен **Python 3.10+**, сторонних зависимостей нет. Склонируйте или скачайте
репозиторий, откройте терминал в его корне и проверьте интерпретатор:

```powershell
cd TVDSL-HW
python --version
```

В Linux/macOS замените `python` на `python3`, если требуется. Установка пакетов
и создание виртуального окружения не обязательны.

## HW1 — лексер и автоматы

`funnylex/` строит НКА Томпсона, ДКА методом подмножеств и минимальный ДКА
Хопкрофта по [tokens.spec](tokens.spec). Сканер использует только таблицу
[generated/dfa.min.json](generated/dfa.min.json), сохраняет позиции токенов,
выбирает самое длинное совпадение, а при равной длине — первое правило.

Все команды выполняются из корня репозитория:

```powershell
python -m funnylex build
python -m funnylex test
python -m unittest discover -s tests
python -m funnylex lex --text 'r = 007 + x$y; // comment'
python -m funnylex lex program.funny --keep-skipped
```

- `build` записывает JSON/CSV/DOT в `generated/`.
- `test` проверяет 102 строки: токены, пробелы, комментарии, приоритеты и ошибки.
- `unittest` запускает 13 тестов алгоритмов, включая сравнение с `re` и независимой минимизацией.
- `lex` выводит строку, столбец, имя токена и лексему. `--keep-skipped` показывает пробелы и комментарии.

48 правил дают **301 состояние НКА → 126 ДКА → 123 минимального ДКА**.
Ловушка — состояние `1`: все переходы ведут в него же. Алфавит HW1 — ASCII;
любой символ вне ASCII даёт ошибку, в том числе внутри комментария.
`BAD_INT` распознаёт `00`, `01`, `007` как одну ошибку числа с ведущим нулём.
Регулярные выражения поддерживают `|`, конкатенацию, `*`, `+`, `?`, скобки,
классы, точку и экранирование; порядок правил задаёт приоритет токенов.

Коды завершения: `0` — успех; `1` — лексические ошибки или упавшие тесты;
`2` — ошибка файла, регулярного выражения или аргументов команды.
