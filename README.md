# TVDSL-HW

Домашние задания по курсу [TVDSL](https://github.com/nsu-fit/TVDSL).

- [HW1 — лексический анализ](HW1/README.md): установка, построение автоматов, запуск лексера и тестов.
- [HW2 — синтаксический анализ](HW2/README.md): установка, разбор Funny, AST, диагностика и тесты.

Первое и второе ДЗ находятся в соседних папках. Команды из обоих README выполняются из корня репозитория.

```text
TVDSL-HW/
├── README.md
├── .gitignore
├── HW1/
│   ├── README.md
│   ├── funnylex/
│   ├── generated/
│   ├── tests/
│   └── tokens.spec
└── HW2/
    ├── README.md
    ├── funnyparse/
    ├── examples/
    ├── tests/
    └── grammar.ebnf
```
