# Граф из P09

| Файл | Переходы |
| --- | --- |
| p09_waiting.pml | s0 → s1, s1 → s1 или s2, s2 → s0, s3 → s3 |
| p09_without_waiting.pml | Из исходного графа удалён переход s1 → s1 по упражнению 6 |

Начальное состояние s0. s1 означает запрос, s2 — подтверждение,
s3 — ошибку. Условий fairness нет.

| Свойство | С петлёй s1 → s1 | После удаления петли |
| --- | --- | --- |
| `G (state != s3)` | Верно | Верно |
| `G ((state == s1) -> F (state == s2))` | Нарушено | Верно |
| `G ((state == s2) -> F (state == s0))` | Верно | Верно |

В исходном графе путь `s0 → s1 → [s1]...` бесконечно откладывает ответ.
Интеграционный тест запускает Spin, воспроизводит этот контрпример
и проверяет, что на повторяемом цикле присутствует s1 и отсутствует s2.
