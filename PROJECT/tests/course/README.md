# Примеры проекта TVDSL

В `original/` лежат все 42 исходника из четырнадцати папок
`TVDSL/project/examples`. Файлы скопированы без изменения содержимого.
Ревизия и SHA256 каждого файла записаны в `source.json`, лицензия курса
сохранена в `LICENSE`.
[Исходники курса](https://github.com/nsu-fit/TVDSL/tree/549d9247f65a2a5344fcf838f2fc6150cff06856/project/examples).

`cases.json` задаёт аргументы, функцию, результат или ожидаемую диагностику.
Все 18 файлов `bad_*` должны быть отклонены по указанной причине.
Для 23 вычислительных примеров проверяются IR и байт-код JVM до и после
оптимизации, включая пустые массивы, разные ветви и ноль итераций цикла.
У `safe_div` также проверяются включённые проверки assert/assume.

В компиляторе проекта локальная переменная может вводиться первым присваиванием.
Так непосредственно исполняются примеры с i, p, q и другими локальными именами.
Тесты читают исходные файлы из `original/`.

## Противоречие в good_while_nested

`step05/good_while_nested.funny` содержит `n = n - 1`, хотя n объявлен
параметром. ТЗ проекта прямо запрещает присваивать параметры. Для этого
исходного файла тест ожидает `readonly_assignment` с именем n.
[Требования к параметрам](https://github.com/nsu-fit/TVDSL/blob/549d9247f65a2a5344fcf838f2fc6150cff06856/project/project_spec.md#целевая-платформа-и-abi-обязательные-требования).

## Запуск

```powershell
python -m unittest discover -s PROJECT/tests -p test_course_examples.py -v
```

Каждый исходник выводится отдельной строкой. Тест инвентаризации проверяет,
что все скопированные файлы присутствуют в эталонах и совпадают с SHA256.
Другой экземпляр репозитория TVDSL для прогона не требуется.
